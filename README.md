# Погодный экран и Wi-Fi-повторитель на CYD

**Погодный экран и Wi-Fi-повторитель с NAT на одной плате.** CYD показывает погоду, время и дату, подключается к домашней сети и одновременно создаёт собственную Wi-Fi сеть для клиентов.

## Плата

Используется **ESP32-2432S028**, известная как **CYD (Cheap Yellow Display)**:

- классический двухъядерный ESP32-WROOM-32, 240 МГц;
- 4 МБ flash;
- цветной 2,8-дюймовый TFT 320×240 на контроллере ILI9341;
- встроенный резистивный сенсор XPT2046 — в этой прошивке он не задействован;
- Wi-Fi 2,4 ГГц 802.11 b/g/n.

Экранная часть собрана на `TFT_eSPI` с профилем `ILI9341_2`; русские подписи выводит `U8g2_for_TFT_eSPI`. Используются выводы CYD: MOSI GPIO13, SCLK GPIO14, CS GPIO15, DC GPIO2, RST GPIO12 и подсветка GPIO21.

## Что объединено

Вместо двух отдельных прошивок сделано одно приложение:

1. **Погодная прошивка** рисует русский экран с городом, временем, датой, температурой, описанием погоды, влажностью и ветром. Текущие данные загружаются с `wttr.in`; поиск города использует геокодирование Open-Meteo. Погода обновляется раз в 15 минут.
2. **Режим роутера** работает как Wi-Fi-клиент (`STA`) и точка доступа (`AP`) одновременно. NAT и IP-forwarding включаются через ESP-NETIF NAPT, поэтому подключённые к CYD устройства могут выходить в интернет через домашнюю сеть.
3. **Веб-настройки** обслуживаются самой платой. В браузере задаются домашний Wi-Fi, имя и пароль сети CYD, город и часовой пояс, а также URL трёх текстовых файлов на хостинге. Настройки хранятся во flash в NVS и переживают перезапуск.

Для времени используются NTP-серверы `pool.ntp.org` и `time.nist.gov`. Часовой пояс по умолчанию — UTC+7, его можно изменить на странице настроек.

## Тексты по сегодняшней дате

В веб-настройках есть три поля URL: «Этот день в истории», «Праздники России» и «Праздники мира». Укажите прямые ссылки на `.txt` файлы, например `https://example.com/1.txt`. Плата загружает их после синхронизации часов и выбирает все строки, начинающиеся с сегодняшней даты в формате `ДД.ММ — текст`. Если в файле несколько строк с одной датой, они показываются вместе отдельными строками. Пустая ссылка отключает файл.

Карточки идут по кругу: файл 1 — 5 секунд, файл 2 — 5 секунд, файл 3 — 5 секунд, затем экран погоды, времени и даты — 30 секунд. Дата выделена жёлтым, записи белые на тёмном фоне. Список обновляется при смене дня; при ошибке загрузки выполняются повторные попытки. Для HTTPS используется TLS-клиент с отключённой проверкой сертификата, так как ссылка задаётся пользователем и сертификат заранее неизвестен; размещайте публичные TXT-файлы на доверенном хостинге.

## Подключение и настройка

Для этой платы сеть по умолчанию называется `CYD-Weather-FE68`, пароль — `cydweather`. Суффикс SSID берётся из идентификатора конкретного ESP32 и на других платах будет отличаться.

1. Подключите телефон или компьютер к Wi-Fi сети CYD.
2. Откройте `http://192.168.4.1`.
3. Введите SSID и пароль домашней сети, имя и пароль раздаваемой сети, город и часовой пояс.
4. Нажмите «Сохранить и перезапустить». После перезапуска плата подключится к upstream Wi-Fi и продолжит раздавать сеть.
5. Подключите клиентские устройства к новой сети CYD. Страница состояния показывает, подключён ли upstream и включена ли маршрутизация.

Если плата уже настроена, страницу можно открыть через её адрес в домашней сети. Этот адрес показывается в списке клиентов домашнего роутера или в UART-логе. Для повторного входа в режим настройки удерживайте BOOT около 2,5 секунды.

Пароль раздаваемой сети должен содержать не менее 8 символов. Пустое поле пароля оставляет текущий пароль. После первой настройки рекомендуется заменить пароль по умолчанию.

## Скорость и ограничения

Ориентир для ESP32 NAT-повторителя — примерно **5–15 Мбит/с** в хороших условиях; это диапазон, опубликованный в проекте ESP32 NAT Router. Здесь значение указано в мегабитах в секунду (**Мбит/с**): 10–15 Мбит/с соответствуют примерно 1,25–1,9 МБ/с. Результат зависит от сигнала, помех, домашнего роутера и клиентского устройства. [Описание производительности ESP32 NAT Router](https://github.com/martin-ger/esp32_nat_router/blob/master/README.md)

В прошивке задана ширина канала HT40 для точки CYD и upstream-клиента; набор протоколов b/g/n оставлен для совместимости. Реальная ширина станет 40 МГц, только если её поддерживают upstream-роутер и подключённое устройство. ESP32-WROOM-32 указывает для 802.11n физическую скорость до 150 Мбит/с, но это радиолинк, а не скорость NAT-передачи данных. [Технические характеристики ESP32-WROOM-32](https://documentation.espressif.com/esp32-wroom-32_datasheet_en.html)

У ESP32 одна Wi-Fi-радиосистема и один канал. В режиме AP+STA сеть CYD использует канал домашней точки доступа; выбрать для неё независимый канал нельзя. [Документация ESP-IDF о режиме AP+STA](https://docs.espressif.com/projects/esp-idf/en/v5.5/esp32/api-reference/network/esp_wifi.html)

Чтобы приблизиться к верхней границе:

- поставьте CYD рядом с домашним роутером и клиентские устройства недалеко от CYD;
- подключайте upstream именно к сети 2,4 ГГц — 5 ГГц эта плата не поддерживает;
- используйте HT40 на домашнем роутере, если эфир 2,4 ГГц свободен; при сильных помехах 20 МГц может дать стабильнее и быстрее результат;
- помните, что все устройства на одной точке делят доступное радио-время.

Режим энергосбережения Wi-Fi отключён. В UART проверены включение NAPT, подключение к upstream, загрузка погоды и синхронизация часов. Отдельный измеритель скорости на клиентском устройстве пока не запускался, поэтому 10–15 Мбит/с — ориентир, а не обещание конкретной скорости. Для 10–15 **МБ/с** (80–120 Мбит/с) классическая CYD как программный Wi-Fi-повторитель не подходит.

## Сборка и загрузка

Проект собирается в PlatformIO на Arduino-ESP32 3.3.9 (на базе ESP-IDF 5.5.4). Образ занимает около 1,12 МБ из 1,31 МБ доступного раздела приложения на плате с 4 МБ flash.

```powershell
python -m platformio run -e cyd
python -m platformio run -e cyd -t upload --upload-port COM3
```

Если Windows использует консольную кодовую страницу CP1251, перед командами можно выполнить `$env:PYTHONUTF8 = '1'`, чтобы вывод PlatformIO/esptool не ломался на Unicode-символах.

Исходник приложения находится в `src/main.cpp`, параметры PlatformIO и распиновка TFT — в `platformio.ini`. Сборочные файлы PlatformIO (`.pio`) в репозиторий не включаются.
