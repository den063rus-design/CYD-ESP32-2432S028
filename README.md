# CYD Weather Router

Объединённая прошивка для **ESP32-2432S028 CYD**: экран ILI9341 показывает дату, время и погоду, а плата одновременно подключается к домашнему Wi-Fi и раздаёт сеть клиентам через NAT.

## Доступ к плате

- Домашняя сеть подключается как WAN/upstream.
- Точка доступа по умолчанию: `CYD-Weather-FE68`, пароль `cydweather`.
- Страница настройки доступна по адресу `http://192.168.4.1`, когда телефон или компьютер подключён к точке CYD.
- Если домашний роутер разрешает доступ между Wi-Fi-клиентами, веб-страница также открывается по адресу платы в домашней сети; при первой загрузке в текущем роутере это `192.168.1.114`.
- На странице настроек можно менять домашнюю сеть, имя и пароль раздачи, город и часовой пояс. После сохранения плата перезапускается.
- Параметры сети и города хранятся во flash и переживают перезагрузку.

На странице состояния отображается статус маршрутизации. На плате она считается активной, когда домашний Wi-Fi подключён и NAT включён. Веб-страница и настройки доступны также при неподключённом upstream.

## Дисплей, погода и время

Погода запрашивается у `wttr.in` каждые 15 минут. Часы синхронизируются через NTP; для Красноярска используется UTC+7. На экране подписи и сведения о погоде выводятся по-русски.

## Сборка

Проект использует PlatformIO, Arduino-ESP32 3.3.9 / ESP-IDF 5.5.4 и TFT_eSPI с профилем ILI9341_2 для этой CYD. Сборка проверена для классического ESP32 с 4 МБ flash; приложение занимает около 1,12 МБ из 1,31 МБ доступного раздела.

```powershell
python -m platformio run -e cyd
python -m platformio run -e cyd -t upload --upload-port COM3
```

Если Windows использует консольную кодовую страницу CP1251, перед командой загрузки можно выполнить `$env:PYTHONUTF8 = '1'`, чтобы PlatformIO корректно показывал вывод esptool.

При смене прошивки раздел настроек NVS сохраняется. На подключённой плате проверены запуск точки доступа, подключение к upstream, активация NAPT, запрос погоды и синхронизация времени.
